# Happy Birthday, Sayang! 🎀

Website ulang tahun sederhana yang siap dipublikasikan lewat GitHub Pages.

## Isi folder
- `index.html` — halaman utama
- `assets/foto-ulang-tahun.jpg` — foto yang diberikan
- `assets/lagu-ulang-tahun.mp3` — lagu yang diberikan

## Cara publish ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `birthday-surprise`.
2. Upload **semua isi folder ini** (file `index.html` dan folder `assets`), bukan hanya file ZIP.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai. GitHub akan menampilkan alamat website kamu di bagian Pages.

## Cara mengubah ucapan
Buka `index.html` lalu cari teks `Sayang`, `Dear, Sayang`, atau paragraf surat untuk menggantinya sesuai keinginan.

Catatan: musik tidak otomatis menyala karena browser biasanya memerlukan pengunjung menekan tombol play terlebih dahulu.
